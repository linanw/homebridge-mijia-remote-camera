03 · 声音与夜视

摄像头功能

读取摄像头实际模式后可修改。

Apple“家庭”提供“手动夜视”和“自动夜视”两个互斥开关，分别设置常开和自动模式。关闭当前开启的开关会关闭夜视；两者表示模式，不代表红外灯此刻是否点亮。

功能配置保存后需重启摄像头子桥。对讲时，在“家庭”直播页面使用对讲按钮。

正在读取 Matter 状态…

仅支持可直接互通的局域网；当前不使用 STUN 或 TURN。请填写 Homebridge 容器内实际连接局域网的网卡名称。

配对码仅供管理员在自己的控制器中使用，请勿转发。此处内容不会加入脱敏诊断。

首次连接可能需要一两分钟。提供实时视频、快照、现场声音和双向对讲；夜视模式可在上方控制。

配件发布后，在“Apple 家庭 → 添加配件 → 更多选项”中选择摄像头，使用摄像头启动日志中的 Setup Code 添加；子桥配对码可能与主桥不同。

登录数据只保存在 Homebridge 的私有插件目录，不写入插件配置。
